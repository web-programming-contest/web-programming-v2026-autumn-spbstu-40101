# Лабораторная работа 2

## Задание

Вариант 32. Реализовать функцию findLongestPalindrome(str), которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Решение использует алгоритм расширения от центра. Для каждого возможного центра
проверяются палиндромы нечётной и чётной длины. Функция возвращает найденную
подстроку. Для пустой строки возвращается пустая строка. Функция экспортируется
как именованный ES module export.

## Запуск

Функция находится в файле solution.js. Для проверки импортировать
findLongestPalindrome как именованный экспорт и вызвать с тестовыми строками.
