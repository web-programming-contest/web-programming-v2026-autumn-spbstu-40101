# Лабораторная работа 1

## Задание

Вариант 32. Сверстать флаг Японии. Разместить красный круг по центру полотнища с
помощью position: absolute так, чтобы он оставался по центру при изменении
размеров флага.

## Реализация

Страница реализована с использованием HTML и CSS. Для полотнища задано
соотношение сторон 3:2 и свойство position: relative. Круг размещается с помощью
position: absolute, top: 50%, left: 50% и transform: translate(-50%, -50%).
Размеры полотнища адаптируются к ширине доступной области.

## Запуск

Открыть файл index.html в браузере.
