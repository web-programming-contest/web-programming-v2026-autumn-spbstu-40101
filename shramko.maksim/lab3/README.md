# Лабораторная работа 3

## Задание

Вариант 32. Реализовать функцию difference(arr1, arr2), которая возвращает
массив элементов первого массива, отсутствующих во втором массиве.

## Реализация

Функция создаёт множество Set из элементов второго массива, затем использует
метод filter для формирования нового массива из элементов первого массива,
которых нет во множестве. Исходные массивы не изменяются. Функция экспортируется
как именованный ES module export.

## Запуск

Функция находится в файле solution.js. Для проверки необходимо импортировать
именованный export difference как ES module и вызвать функцию с тестовыми
массивами.
