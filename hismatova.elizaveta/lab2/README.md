# Лабораторная работа 2

## Задание

Вариант 14.

Написать функцию, которая преобразует цвет из HEX-формата в RGB-формат
(например, "#FF0000" -> "rgb(255, 0, 0)").

## Реализация

Логика работы функции hex Torgb заключается в парсинге НЕХ-кода и возврате
строки вида rgb(r, g, b). Обработка ошибок включает проверку типа данных
(ожидается строка), длины (ровно 7 символов) и корректности формата. При
несоответствии любому из условий вызывается исключение.

## Запуск

Функция доступна через именованный экспорт в файле solution.js. Используйте
синтаксис ES-модулей для импорта.

Пример использования:

```javascript
import {hexToRgb} from './solution.js';
console.log(hexToRgb('#FF0000')); // "rgb(255, 0, 0)"
```
