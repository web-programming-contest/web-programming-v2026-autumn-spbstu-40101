# Лабораторная работа 3

## Задание

Вариант 14.

Реализуйте функцию countOccurrences(arr), которая возвращает объект с
количеством вхождений каждого элемента.

## Реализация

Функция `countOccurrences(arr)` принимает массив и возвращает объект с
количеством вхождений каждого элемента. При передаче пустого массива
возвращается пустая мапа. Для непустых массивов формируется объект, где ключ —
элемент массива, а значение — число его повторений.

## Запуск

Импортируйте функцию `countOccurrences` из `solution.js` как ES-модуль.

Пример использования:

```javascript
import {countOccurrences} from './solution.js';
console.log(countOccurrences([1, 2, 2, 3, 3, 3])); // { '1': 1, '2': 2, '3': 3 }
console.log(countOccurrences([])); // {}
```
