# Лабораторная работа 3

## Задание

Вариант 33. Задача 3. Реализуйте функцию shuffleArray(arr), которая перемешивает
элементы массива в случайном порядке.

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

Алгоритм: Используется тасование Фишера — Йетса, которое даёт равномерное
распределение перестановок за O(n).

Граничные случаи:

- пустой массив → `[]`;
- массив из одного элемента → копия с тем же элементом;
- массив с любыми типами элементов (числа, строки, объекты, `undefined`) —
  элементы не преобразуются;
- если аргумент не массив, выбрасывается `TypeError`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
