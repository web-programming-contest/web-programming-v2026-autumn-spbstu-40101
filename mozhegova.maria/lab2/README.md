# Лабораторная работа 2

## Задание

Вариант 33. Задача 2. Реализовать функцию countVowels(str), которая возвращает
количество гласных букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

Алгоритм:

1. Строка приводится к нижнему регистру через `toLowerCase()`, поэтому `A` и `a`
   считаются одинаково.
2. Выполняется проход по символам строки; каждый символ проверяется на
   принадлежность множеству `{a, e, i, o, u}`.
3. Функция возвращает количество найденных гласных.

Граничные случаи:

- пустая строка → `0`;
- строка без гласных (`"rhythm"`, цифры, пробелы, знаки) → `0`;
- гласные в верхнем и смешанном регистре (`"AEIOU"`, `"Hello"`) учитываются;
- если передан не строковый аргумент, возвращается `0`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
