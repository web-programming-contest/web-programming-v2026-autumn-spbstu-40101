# Лабораторная работа 1

## Задание

Вариант 33. Задача 1: создать три карточки товара. Каждая карточка — `div`-блок,
содержащий:

- изображение 200px на 150px;
- заголовок (Arial, 18px, жирный);
- описание (Arial, 14px). Карточки расположены в одну строку с отступом 20px
  между ними. Для всех элементов используется `padding: 10px`.

## Реализация

- `index.html` — семантическая разметка: `main` → `section.cards` → три
  `div.card` (`img`, `h2`, `p`). Изображения встроены как SVG data URI.
- `styles.css` — `display: flex` и `gap: 20px` для расположения карточек в
  строку; `padding: 10px` у карточки, изображения, заголовка и описания;
  `box-sizing: border-box` задаёт изображению размер ровно 200×150px. Контейнер
  имеет `overflow-x: auto`, чтобы на узких экранах страница не получала
  горизонтальный overflow.

## Запуск

Откройте `index.html` в браузере.
