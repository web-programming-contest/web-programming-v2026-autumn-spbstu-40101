# Лабораторная работа 3

## Задание

Вариант 27. Реализуйте функцию rotateArray(arr, steps), которая сдвигает массив
вправо на steps элементов.

## Реализация

Простейшее склеивание двух обрезков реализует циклический сдвиг вправо на steps
элементов.

1. Проверку на пустой массив можно и не делать так то, но лишним не будет.
2. Если steps больше длины массива, то всё работает нормально, js сам правильно
   обрежет.
3. Подразумевается, что steps > 0, поэтому при отрицательых steps массив влево
   не сдвигается.
4. По умолчанию steps = 0.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
