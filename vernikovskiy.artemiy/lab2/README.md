# Лабораторная работа 2

## Задание

Вариант 27. Написать функцию toRoman(num), преобразующую число в римскую запись
(до 3999).

## Реализация

Алгоритм решения "в лоб". Завели словарик с соответствующими числами и их
римским написанием и строим число от большего к меньшему последовательно вычитая
записанное.

1. Отсчёт от 1, так как для отрицательных и нуля римляне ничего не придумали.
2. Если дробное, или превышает 3999 просто возвращаем пустую строку.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
