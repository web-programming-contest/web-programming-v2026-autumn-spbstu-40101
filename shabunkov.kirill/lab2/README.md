# Лабораторная работа 2

## Задание

Вариант 24. Реализовать функцию `zipArrays(...arrays)`, которая объединяет
переданные массивы поэлементно.

## Реализация

Функция экспортируется как именованный ES module export. С помощью
rest-параметра она принимает произвольное количество массивов, определяет длину
самого короткого массива и создаёт новый массив из элементов с одинаковыми
индексами. Исходные массивы не изменяются.

## Запуск

Импортируйте функцию `zipArrays` из файла `solution.js` и вызовите её, передав
необходимые массивы.
