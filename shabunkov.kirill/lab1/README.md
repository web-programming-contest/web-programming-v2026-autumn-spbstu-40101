# Лабораторная работа 1

## Задание

Вариант 24. Создать регистрационную форму с полями имени, фамилии, электронной
почты, пароля, подтверждения пароля, даты рождения, страны и согласия с
условиями. Между полями должен быть отступ 20px. Фон формы - белый, текст -
чёрный, кнопка отправки - зелёная с белым текстом.

## Реализация

Форма создана с использованием семантических HTML-элементов и корректных типов
полей ввода. Оформление вынесено в отдельный CSS-файл. Для расположения полей и
отступов используется Flexbox.

## Запуск

Откройте `index.html` в браузере.
