# Лабораторная работа 3

## Задание

Вариант 24. Реализовать функцию `maxSlidingWindow(arr, k)`, которая находит
максимальные значения во всех последовательных подмассивах длины `k`.

## Реализация

Функция использует очередь индексов потенциальных максимумов. Из начала очереди
удаляются элементы, которые вышли за границы текущего окна, а из конца —
элементы, не превышающие текущий. Благодаря этому максимум каждого окна
находится в начале очереди. Исходный массив не изменяется.

Для некорректного размера окна функция возвращает пустой массив.

## Запуск

Импортируйте функцию `maxSlidingWindow` из файла `solution.js` и передайте ей
массив чисел и размер окна.
