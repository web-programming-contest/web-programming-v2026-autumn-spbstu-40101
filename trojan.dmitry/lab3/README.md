# Лабораторная работа 3

## Задание

Вариант 3.

Реализовать функцию findMostFrequent(arr), которая принимает массив и возвращает
наиболее часто встречающийся элемент.

Пример: findMostFrequent([1, 2, 2, 3, 3, 3, 4]) → 3

## Реализация

Решение находится в файле solution.js.

Функция findMostFrequent(arr) использует два цикла for...of.

Первый цикл проходит по элементам массива и подсчитывает количество повторений
каждого элемента.

Результаты подсчёта сохраняются в объекте counts, где ключ — элемент массива, а
значение — количество его повторений.

Второй цикл повторно проходит по массиву и определяет элемент с максимальным
количеством повторений.

Для этого используются две переменные:

- mostFrequent — наиболее часто встречающийся элемент.
- maxCount — максимальное количество повторений.

Если несколько элементов встречаются одинаковое максимальное количество раз,
возвращается первый из них в исходном массиве.

Функция не изменяет исходный массив и возвращает результат через return.

Для автоматических тестов используется именованный export.

## Запуск

Для запуска требуется Node.js.

Из корня репозитория выполнить:

node --input-type=module -e "import { findMostFrequent } from
'./trojan.dmitry/lab3/solution.js';
console.log(findMostFrequent([1,2,2,3,3,3,4]));"

Ожидаемый результат: 3.
