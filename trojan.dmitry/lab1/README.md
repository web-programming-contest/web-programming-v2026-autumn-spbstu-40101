# Лабораторная работа 1

## Задание

Вариант 3.

Создать три прямоугольных div-элемента:

- Центральный прямоугольник — зелёный, с относительным позиционированием.
- Левый прямоугольник — красный, с абсолютным позиционированием, расположен под
  зелёным.
- Правый прямоугольник — синий, с абсолютным позиционированием, расположен над
  зелёным.

Красный и синий прямоугольники должны частично перекрывать центральный. Для
управления расположением использовать свойства top, right, bottom, left, а для
порядка наложения — z-index.

## Реализация

Структура страницы описана в файле index.html. Стили находятся в файле
styles.css.

Создан контейнер размером 600 на 300 пикселей с position: relative.

Внутри контейнера расположены три прямоугольника размером 200 на 120 пикселей.

Зелёный прямоугольник использует position: relative и центрируется по
горизонтали с помощью margin: 0 auto.

Красный и синий прямоугольники используют position: absolute. Их расположение
настраивается с помощью top, left и right.

Порядок наложения определяется свойством z-index:

- Красный: 1.
- Зелёный: 2.
- Синий: 3.

## Запуск

Открыть файл index.html в браузере.

Для автоматического обновления страницы при изменениях можно использовать
расширение Live Server в Visual Studio Code.
