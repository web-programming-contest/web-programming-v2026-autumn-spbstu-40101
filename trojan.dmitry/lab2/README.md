# Лабораторная работа 2

## Задание

Вариант 3.

Реализовать функцию calculateExpression(expr), которая принимает математическое
выражение в виде строки и возвращает результат вычисления.

Пример: "2 + 3 * 4" → 14

Функция должна учитывать приоритет математических операций.

## Реализация

Решение находится в файле solution.js.

Функция calculateExpression(expr) принимает строку с математическим выражением.

С помощью регулярного выражения match() строка разделяется на числа и
математические операторы.

Числовые строки преобразуются в числа с помощью Number().

Для вычисления используется вспомогательная функция calculate(), которая
выбирает арифметическую операцию с помощью switch case.

Приоритет математических операций реализован двумя циклами:

- Первый цикл выполняет умножение и деление.
- Второй цикл выполняет сложение и вычитание.

Метод splice() заменяет выполненную операцию её результатом.

После завершения вычислений функция возвращает итоговое число с помощью return.

Функция экспортируется через именованный export для автоматических тестов.

## Запуск

Для запуска требуется Node.js.

Из корня репозитория можно выполнить:

node --input-type=module -e "import { calculateExpression } from
'./trojan.dmitry/lab2/solution.js'; console.log(calculateExpression('2+3*4'));"

Ожидаемый результат: 14.
