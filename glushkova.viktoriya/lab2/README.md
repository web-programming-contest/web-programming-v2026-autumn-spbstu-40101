# Лабораторная работа 2

## Задание

Вариант 35. Написать функцию `findMissingNumber(arr)`, находящую пропущенное
число в массиве целых чисел от 1 до N (одно пропущено).

## Реализация

Функция `findMissingNumber` экспортируется как именованный ES module export из
`solution.js`. Решение основано на математической формуле суммы арифметической
прогрессии. Сначала вычисляется максимальное число N (длина массива + 1). Затем
вычисляется ожидаемая сумма чисел от 1 до N по формуле N * (N + 1) / 2. После
этого вычисляется фактическая сумма элементов массива с помощью метода reduce.
Разница между ожидаемой и фактической суммой является пропущенным числом.
Входной массив не изменяется.

## Запуск

Импортируйте функцию `findMissingNumber` из файла `solution.js` и вызовите её,
передав массив чисел.
