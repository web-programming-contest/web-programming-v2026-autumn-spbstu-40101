# Лабораторная работа 1

## Задание

Вариант 35. Создать постраничную навигацию. Требования: элементы навигации
расположены по центру; текст внутри элемента выровнен по центру по двум осям;
фон активного элемента отличается от остальных; фон элемента при наведении
изменяется.

## Реализация

Разметка выполнена в `index.html` с использованием семантического элемента `nav`
с `aria-label`. Элементы навигации — ссылки `a`, активный элемент помечен
классом `active` и атрибутом `aria-current="page"`.

Стили в `styles.css`:

- контейнер `.page` центрирует навигацию по двум осям через flex;
- `.pagination` — flex-контейнер со `gap` для зазоров между кнопками;
- `.pagination-item` — квадратная кнопка с flex-центрированием текста по двум
  осям;
- hover-состояние задано через `:hover` для неактивных элементов;
- `:focus-visible` обеспечивает видимый фокус для клавиатуры.

## Запуск

Открыть файл `index.html` в браузере.
