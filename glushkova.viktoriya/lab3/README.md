# Лабораторная работа 3

## Задание

Вариант 35. Реализовать функцию `findMedian(arr)`, которая вычисляет медиану
числового массива.

## Реализация

Функция `findMedian` экспортируется как именованный ES module export из
`solution.js`. Для начала проверяется, что входные данные являются массивом и он
не пуст. Затем создается копия массива с помощью спред-оператора, чтобы не
изменять исходный массив, и она сортируется по возрастанию. Вычисляется индекс
среднего элемента. Если длина массива нечетная, возвращается центральный
элемент. Если четная — возвращается среднее арифметическое двух центральных
элементов.

## Запуск

Импортируйте функцию `findMedian` из файла `solution.js` и вызовите её, передав
массив чисел.
