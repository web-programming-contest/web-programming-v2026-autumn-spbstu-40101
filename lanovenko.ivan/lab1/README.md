# Лабораторная работа 1

## Задание

Вариант 11. Создать список задач, в котором каждый элемент списка имеет
отдельную иконку вместо стандартного маркера — в зависимости от статуса задачи:

- задача выполнена;
- задача отменена;
- задача в процессе выполнения.

Иконки добавляются с помощью псевдоэлементов CSS и Unicode-символов.

## Реализация

Страница состоит из семантического контейнера `<main>`, заголовка `<h1>` и
неупорядоченного списка `<ul class="task-list">`. Каждый пункт списка —
`<li class="task">` с модификатором статуса:

- `task-done` — выполненная задача;
- `task-cancelled` — отменённая;
- `task-in-progress` — задача в процессе выполнения.

Стандартные маркеры списка отключены (`list-style: none`), вместо них иконки
рисуются через псевдоэлемент `::before` соответствующего класса с помощью
Unicode-эмодзи: `content: "✅"`, `content: "❌"`, `content: "⏳"`. Отменённая
задача дополнительно выделяется зачёркнутым текстом и приглушённым цветом.

Пункты разделены тонкой границей, при наведении курсора фон подсвечивается
(hover-состояние). Вёрстка адаптивная: контейнер ограничен по ширине и
центрируется, горизонтальной прокрутки нет.

## Запуск

Откройте файл `index.html` в браузере — двойным кликом по нему в проводнике или
через расширение Live Server в VS Code. Сборка не требуется, страница
статическая.
