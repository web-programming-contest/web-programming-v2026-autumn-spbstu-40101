# Лабораторная работа 3

## Задание

Вариант 11. Реализовать функцию `findMaxSubarraySum(arr, n)`, которая находит
максимальную сумму подмассива длины `n`.

Пример: `findMaxSubarraySum([1, 2, 3, 4, 5], 2)` → `9` (подмассив `[4, 5]`).

## Реализация

Функция экспортируется по имени `findMaxSubarraySum` как ES module и использует
метод скользящего окна (sliding window) за один проход по массиву.

Алгоритм:

1. Проверяются граничные случаи: если `arr` — не массив, пустой, `n <= 0` или
   `n` больше длины массива, возвращается `0`.
2. Вычисляется сумма первого окна `arr[0] + … + arr[n-1]`.
3. Окно сдвигается вправо: на каждом шаге к текущей сумме прибавляется новый
   элемент `arr[i]` и вычитается ушедший `arr[i-n]`. Максимум обновляется по
   ходу.
4. Возвращается найденный максимум.

Сложность — `O(n)` по времени и `O(1)` по дополнительной памяти. Наивное решение
через двойной цикл было бы `O(n²)`.

Граничные случаи:

- `n` больше длины массива или `n <= 0` → `0`;
- пустой массив → `0`;
- `n === arr.length` → сумма всего массива;
- массив из отрицательных чисел → возвращается максимальная (наименее
  отрицательная) сумма окна, например `[-5, -2, -8]` с `n = 2` даёт `-7`.

Входной массив не мутируется.

## Запуск

Импортируйте именованный export `findMaxSubarraySum` из `solution.js` как ES
module:

```js
import {findMaxSubarraySum} from './solution.js';

console.log(findMaxSubarraySum([1, 2, 3, 4, 5], 2)); // 9
```
