# Лабораторная работа 2

## Задание

Вариант 11. Реализовать функцию `reverseWords(str)`, которая переворачивает
каждое слово во входной строке, сохраняя порядок слов.

Пример: `"Hello world"` → `"olleh dlrow"`.

## Реализация

Функция экспортируется по имени `reverseWords` как ES module. Алгоритм:

1. Регулярным выражением `/\S+/g` находим каждое слово — последовательность
   непробельных символов.
2. Каждое совпадение переворачиваем: разбиваем на символы через spread
   (`[...word]`), затем `reverse()` и `join("")`.
3. Пробельные символы (одинарные и двойные пробелы, табы, переводы строк) не
   изменяются — благодаря `String.prototype.replace` с callback они остаются на
   своих местах.

Использование spread-оператора для разбиения на символы (а не `split("")`)
корректно работает с Unicode-символами за пределами BMP — например, с эмодзи.

Граничные случаи:

- пустая строка → пустая строка;
- строка только из пробелов → возвращается без изменений;
- одно слово → возвращается перевёрнутым;
- несколько пробелов подряд → количество пробелов сохраняется;
- знаки препинания остаются прикреплёнными к слову и переворачиваются вместе с
  ним (`"Hi!"` → `"!iH"`).

Входная строка не мутируется.

## Запуск

Импортируйте именованный export `reverseWords` из `solution.js` как ES module:

```js
import {reverseWords} from './solution.js';

console.log(reverseWords('Hello world')); // "olleh dlrow"
```
