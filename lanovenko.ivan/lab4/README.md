# Лабораторная работа 4

## Задание

Задача 4 (укажите здесь номер своего варианта).

Модель: класс `User` с полями `id`, `name`, `friends`, методами `addFriend`,
`removeFriend` и геттером `friendCount`. Функции коллекции: группировка
пользователей по количеству друзей, уникальный список друзей, пользователи с
общим другом, пользователи с числом друзей больше заданного, пользователи без
друзей.

Интерфейс: список карточек пользователей (имя, ID, друзья), формы создания
пользователя и добавления друга, кнопки добавления и удаления друзей и
пользователей. Все операции выполняются асинхронно через `Promise` и
`setTimeout`, состояние хранится в `localStorage`.

## Реализация

`model.js` содержит класс `User` и функции `groupUsersByFriendCount`,
`getUniqueFriends`, `getUsersWithCommonFriend`, `getUsersWithMoreFriendsThan`,
`getUsersWithoutFriends`. Функции не изменяют входной массив.

`main.js` хранит список пользователей, оборачивает каждое изменение в `Promise`
с `setTimeout`, после операции сохраняет данные в `localStorage` и заново
отрисовывает карточки. При удалении пользователя его id убирается из списков
друзей остальных. Ошибки (дубликат ID, несуществующий пользователь, добавление
себя в друзья) выводятся в сообщении под формой.

## Запуск

Откройте `index.html` в браузере (или запустите любой локальный сервер, так как
`main.js` подключён как ES module).
