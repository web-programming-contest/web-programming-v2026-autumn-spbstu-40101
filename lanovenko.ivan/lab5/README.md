# Лабораторная работа 5

## Задание

Вариант 11. Создать шахматную игру.

Создайте интерактивную шахматную игру с возможностью игры против игрока. Проект
должен включать шахматную доску с фигурами, реализацию основных правил и
визуальную обратную связь при ходе.

Функциональность:

- отображение доски с чередующимися светлыми и тёмными клетками;
- перемещение фигур по правилам шахмат;
- определение конца игры (шах и мат);
- подсветка доступных ходов при выборе фигуры.

Логика игры:

- поочерёдные ходы игроков;
- запрет ходов, оставляющих своего короля под шахом;
- автоматическое определение возможных ходов для каждой фигуры.

## Реализация

React-приложение на Vite. Логика правил вынесена в `src/chess.js`, интерфейс — в
`src/main.jsx`.

Состояние партии хранит позицию фигур, очередь хода, права на рокировку, поле en
passant и статус (`playing` / `checkmate` / `stalemate`). При клике по фигуре
текущей стороны считаются легальные ходы: сначала псевдолегальные по типу
фигуры, затем отбрасываются те, после которых король остаётся под шахом.
Доступные клетки подсвечиваются элементами с `data-testid="available-move"`.

Поддержаны рокировка, взятие на проходе и превращение пешки в ферзя. Ход
выполняется повторным кликом по подсвеченной клетке. Кнопка «Новая партия»
сбрасывает доску в начальную позицию.

Публичные селекторы для CI: `chess-board`, `chess-cell`, `chess-piece`,
`movable-piece`, `available-move`.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
