# Лабораторная работа 3

## Задание

Вариант 29. Реализовать функцию `mergeArrays(arr1, arr2)`, которая объединяет
два массива, удаляя дубликаты.

## Реализация

Функция `mergeArrays` экспортируется именованно из `solution.js`. Элементы обоих
массивов собираются в `Set`, который отбрасывает повторы и сохраняет порядок
первого появления, затем результат преобразуется в новый массив. Входные массивы
не изменяются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {mergeArrays} from './solution.js';

mergeArrays([1, 2, 2], [2, 3, 1, 4]); // [1, 2, 3, 4]
```
