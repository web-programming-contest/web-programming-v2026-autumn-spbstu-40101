# Лабораторная работа 2

## Задание

Вариант 29. Написать функцию `convertBase(num, fromBase, toBase)`, преобразующую
число между системами счисления.

## Реализация

Функция `convertBase` экспортируется именованно из `solution.js`. Число (строка
или число) разбирается по цифрам в исходном основании в `BigInt`, затем
переводится делением в целевое основание. Поддерживаются основания от 2 до 36,
знак `-`, регистр цифр не важен, результат возвращается строкой в верхнем
регистре. Ноль возвращается как `"0"`. Для недопустимых оснований и цифр
выбрасывается ошибка.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {convertBase} from './solution.js';

convertBase('1010', 2, 10); // "10"
convertBase('255', 10, 16); // "FF"
```
