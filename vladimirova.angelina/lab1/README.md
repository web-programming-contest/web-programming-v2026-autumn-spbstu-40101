# Лабораторная работа 1

## Задание

Вариант 29. Создать список задач, где вместо классических маркеров у каждого
элемента своя иконка в зависимости от статуса: выполнена — ✅, отменена — ❌, в
процессе — ⏳. Иконки добавляются через CSS-псевдоэлементы с символами Unicode.

## Реализация

Список `ul.task-list` без стандартных маркеров (`list-style: none`). Статус
задачи задаётся классом элемента `li`: `task-done`, `task-cancelled`,
`task-in-progress`. Иконка выводится псевдоэлементом `::before` с `content` в
виде Unicode-кода символа, стили модификаторов не содержат inline-стилей.

## Запуск

Откройте `index.html` в браузере.
