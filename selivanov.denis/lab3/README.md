# Лабораторная работа 3

## Задание

Вариант 29. Объединение двух массивов без дубликатов.

## Реализация

Функция `mergeArrays` в `solution.js` обходит оба массива и вложенным циклом
ищет повторы. Сохраняет порядок элементов и не меняет исходные массивы.

## Запуск

Из корня репозитория:

```bash
node --input-type=module -e "import {mergeArrays} from './selivanov.denis/lab3/solution.js'; console.log(mergeArrays([1, 2], [2, 3]));"
```
