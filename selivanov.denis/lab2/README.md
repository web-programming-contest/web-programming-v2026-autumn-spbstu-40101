# Лабораторная работа 2

## Задание

Вариант 29. Перевод целого числа между системами счисления.

## Реализация

Функция `convertBase` в `solution.js` циклом читает цифры исходного числа, затем
делением с остатком формирует результат. Основания — от 2 до 36, входные данные
корректные, число — в безопасном диапазоне `Number`.

## Запуск

Из корня репозитория:

```bash
node --input-type=module -e "import {convertBase} from './selivanov.denis/lab2/solution.js'; console.log(convertBase('FF', 16, 2));"
```
