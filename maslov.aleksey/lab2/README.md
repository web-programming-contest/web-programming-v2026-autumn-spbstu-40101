# Лабораторная работа 2

## Задание

Вариант 25. Задача 2. Написать функцию findLongestPalindrome(str), которая
находит и возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

findLongestPalindrome(str) возвращает самую длинную подстроку-палиндром,
работает на алгоритме Манакера. Граничные случаи:

1. пустая строка
2. строка без палиндромов длиннее 1 символа -> возвращается первый символ

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
