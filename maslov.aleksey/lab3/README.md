# Лабораторная работа 3

## Задание

Вариант 25. Задача 3. Реализуйте функцию findEquilibriumIndex(arr), которая
находит индекс, где сумма левой и правой части массива равна.

## Реализация

findEquilibriumIndex - находит в массиве чисел индекс, где сумма элементов слева
равна сумме элементов справа; Входные параметры: массив чисел; Возвращаемое
значение: индекс; Если такого индекса нет или массив пуст, возвращается -1.

Алгоритм: проходим по массиву и вычисляем полную сумму, на каждом шаге цикла
вычисляем правую и левую суммы, если равны, то выводим индекс.

Граничные случаи: пустой массив или некорректный ввод

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
