# Лабораторная работа 1

# Вариант 1. Форма регистрации

## Задание

Создать форму регистрации по образцу из задания. Требования:

- ширина формы — 400px;
- внутренний отступ — 8px;
- цвет кнопки — `#0056ff`;
- цвет кнопки при наведении курсора — `#417ffb`.

## Реализация

Файлы: `task1.html` (разметка) и `task1.css` (стили).

Разметка:

1. Вся форма — один элемент `<form class="reg-form">`.
2. Внутри пять полей `<input>` без подписей, подсказки заданы через
   `placeholder`: «Имя», «E-mail», «Телефон», «Пароль», «Пароль еще раз».
3. Типы полей подобраны по смыслу: `text` для имени, `email` для почты, `tel`
   для телефона, `password` для обоих паролей. Все поля обязательные
   (`required`).
4. Внизу кнопка `<button type="submit">Регистрация</button>`.

Стили:

1. `.reg-form` — `width: 400px`, `padding: 8px`, светло-серый фон `#f5f5f5`, как
   на образце.
2. Поля занимают всю ширину формы, имеют белый фон, тонкую серую рамку
   `1px solid #ccc` и отступ снизу 8px.
3. Кнопка на всю ширину, фон `#0056ff`, белый текст, без рамки и скруглений.
   Правило `.reg-form__button:hover` меняет фон на `#417ffb`.
4. Правило `* { box-sizing: border-box; }` нужно, чтобы padding и рамки входили
   в заданные размеры. Без него форма стала бы шире 400px.

Форма никуда не отправляет данные (`action="#"`), это только вёрстка.

## Запуск

Положите `task1.html` и `task1.css` в одну папку и откройте `task1.html` в
браузере. Либо откройте папку в VS Code и запустите страницу через расширение
Live Server (правый клик по файлу, `Open with Live Server`).
