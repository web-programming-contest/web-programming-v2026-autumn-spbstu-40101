# Лабораторная работа 2

# Вариант 1. analyzieString

## Задание

Реализовать функцию `analyzieString`, которая принимает строку и возвращает
объект:

- `letters` — количество букв;
- `digits` — количество цифр;
- `spaces` — количество пробелов;
- `other` — количество остальных символов.

Пример: `"Hello World 123!"` →
`{ letters: 10, digits: 3, spaces: 2, other: 1 }`.

## Реализация

Файл: `task2.js`. Функция реализована вручную, без регулярных выражений и
встроенных методов подсчёта. Алгоритм:

1. Создаём объект результата `{ letters: 0, digits: 0, spaces: 0, other: 0 }`.
2. Проходим по строке циклом `for` по индексам, для каждого символа смотрим его
   код через `charCodeAt(0)`.
3. Символ считается буквой (`isLetter`), если его код лежит в диапазонах `A-Z`
   (65–90), `a-z` (97–122), `А-я` (1040–1103) или это `Ё`/`ё` (1025/1105).
4. Символ считается цифрой (`isDigit`), если код в диапазоне 48–57 (`0-9`).
5. Обычный пробел (`' '`) увеличивает `spaces`.
6. Всё остальное, включая знаки препинания, увеличивает `other`.

Сложность: O(n) по времени, O(1) по памяти.

Граничные случаи:

- пустая строка → `{ letters: 0, digits: 0, spaces: 0, other: 0 }`;
- поддерживаются латиница и кириллица;
- знаки препинания попадают в `other`;
- табы и переводы строк считаются не пробелами, а попадают в `other`: пробелом
  считается только символ `' '`;
- эмодзи и другие символы вне BMP занимают две кодовые единицы в строке
  JavaScript, поэтому каждый даёт `other: 2`.

Входная строка не изменяется.

## Запуск

В конце файла `task2.js` есть примеры вызова с `console.log`. Запуск из
терминала в папке с файлом:

```
node task2.js
```

Файл не является ES-модулем и ничего не экспортирует: функцию можно вызывать
прямо внутри `task2.js` или скопировать в другой скрипт.
