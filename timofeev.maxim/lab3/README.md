# Лабораторная работа 3

# Вариант 1. removeDuplicates

## Задание

Реализовать функцию `removeDuplicates(arr)`, которая возвращает новый массив без
дубликатов. На вход подаётся массив чисел.

Пример: `[1, 2, 2, 5, 6, 7, 5]` → `[1, 2, 5, 6, 7]`.

## Реализация

Файл: `task3.js`. Функция написана вручную, без `Set`, `filter` и `indexOf`.
Алгоритм:

1. Создаём пустой объект `seen`, в нём будем помечать уже встреченные значения,
   и пустой массив `result`.
2. Проходим по входному массиву циклом `for`.
3. Если значения ещё нет в `seen`, добавляем его в `result` и записываем в
   `seen[value] = true`.
4. Если значение уже было, пропускаем его.
5. Возвращаем `result`.

Сложность: O(n) по времени и O(n) по памяти. Двойной цикл со сравнением каждого
элемента с каждым дал бы O(n²).

Граничные случаи:

- пустой массив → `[]`;
- массив без повторов → возвращается его копия;
- все элементы одинаковые → один элемент (`[3, 3, 3]` → `[3]`);
- порядок сохраняется по первому появлению (`[4, 1, 4, 0, 1]` → `[4, 1, 0]`);
- ноль обрабатывается корректно, потому что в `seen` хранится `true`, а не само
  значение.

Ограничение: ключи объекта превращаются в строки, поэтому `1` и `"1"` функция
считает одинаковыми. Для массива чисел из задания это не влияет на результат.

Входной массив не изменяется, возвращается новый.

## Запуск

В конце файла `task3.js` есть примеры вызова с `console.log`. Запуск из
терминала в папке с файлом:

```
node task3.js
```

Файл не является ES-модулем и ничего не экспортирует: функцию можно вызывать
прямо внутри `task3.js` или скопировать в другой скрипт.
