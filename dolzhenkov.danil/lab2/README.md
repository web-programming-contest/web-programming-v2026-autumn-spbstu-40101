# Лабораторная работа 2

## Задание

Вариант 6. Написать функцию `isPerfectNumber`, проверяющую, является ли число
"совершенным" (сумма делителей равна числу, исключая само число).

## Реализация

Внутри функции `isPerfectNumber` запускается цикл от 1 до `number / 2`. В цикле
проверяется, является ли текущее число делителем (с помощью оператора остатка от
деления `%`). Если является, оно прибавляется к общей сумме. В конце функция
сравнивает полученную сумму с исходным числом и возвращает логический результат
(`true` или `false`).

Пример запуска:

node -e "import('./dolzhenkov.danil/lab2/solution.js').then(m =>
console.log(m.isPerfectNumber(6)))"
