# Лабораторная работа 3

## Задание

Вариант 6. Реализовать функцию `intersection(arr1, arr2)`, которая возвращает
массив общих элементов.

## Реализация

Решение находится в файле `solution.js`. Внутри функции используются вложенные
циклы для перебора элементов обоих массивов. При совпадении элементов (проверка
через `===`) число добавляется в третий массив. В конце функция возвращает
сформированный массив.

## Запуск

Пример запуска:

node -e "import('./dolzhenkov.danil/lab3/solution.js').then(m =>
console.log(m.intersection([1, 2, 3, 5, 7, 9], [2, 3, 4, 9])))"
