# Лабораторная работа 1

## Задание

Создать меню блюд с использованием неупорядоченного списка. Каждый пункт должен
состоять из названия блюда и цены. Название должно быть прижато к левому краю,
цена - к правому, независимо от длины текста. Ширина контейнера - 400px, между
пунктами отступ 16px, разделитель - сплошная черная линия 1px.

## Реализация

Структура страницы описана в файле `index.html`. Стили находятся в файле
`styles.css`.

Для разметки использован список `<ul>`, где каждый пункт `<li>` содержит два
тега `<span>` (для названия и цены). Выравнивание по краям реализовано с помощью
Flexbox: для `<li>` задано свойство `display: flex` и
`justify-content: space-between`. Разделительные линии и отступы выполнены с
помощью `border-bottom: 1px solid black` и `margin-bottom: 16px` для всех
элементов, кроме последнего (`:not(:last-child)`).

## Запуск

Открыть файл `index.html` в браузере.
