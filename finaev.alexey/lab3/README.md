# Лабораторная работа 3

## Задание

Реализовать функцию findMaxSubarraySum(arr, n), которая находит максимальную
сумму подмассива заданной длины n.

## Реализация

Для решения задачи используется алгоритм, сложность которого O(N). Сначала
вычисляется сумма первых n элементов, которая принимается за текущий максимум.
Затем окно сдвигается на один шаг вправо: из текущей суммы вычитается элемент,
который выпал из окна, и прибавляется новый элемент. Полученная сумма
сравнивается с максимальной, и при необходимости максимум обновляется.

## Запуск

Функция экспортируется как ES-модуль и может быть вызвана в Node.js.

Пример вызова из корня репозитория:

```bash
node -e "import('./finaev.alexey/lab3/solution.js').then(m => console.log(m.findMaxSubarraySum([1, 2, 3, 4, 5], 2)))"
```
