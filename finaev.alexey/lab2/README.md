# Лабораторная работа 2

## Задание

Реализовать функцию reverseWords(str), которая переворачивает каждое слово в
строке, сохраняя при этом исходный порядок слов.

## Реализация

Внутри функции строка разбивается на массив слов с помощью метода split(' ').
Затем каждый элемент массива обрабатывается: разбивается на массив символов
split(''), переворачивается методом reverse() и собирается обратно в строку
join(''). В конце массив перевернутых слов склеивается в единую строку через
пробел join(' ').

## Запуск

Функция может быть импортирована и вызвана в любом ES-модуле Node.js, в браузере
или напрямую в терминале.

Пример запуска из корня репозитория: node -e
"import('./finaev.alexey/lab2/solution.js').then(m =>
console.log(m.reverseWords('Hello world')))"

Вывод: olleH dlrow
