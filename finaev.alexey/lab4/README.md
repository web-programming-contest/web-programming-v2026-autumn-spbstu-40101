# Лабораторная работа 4

## Задание

1. Создать класс `User` с полями `id`, `name`, `friends` (массив id друзей).
2. Реализовать методы `addFriend`, `removeFriend` и геттер `friendCount`.
3. Реализовать функции для работы с массивом пользователей: группировка по
   количеству друзей, получение уникальных друзей, поиск общих друзей,
   фильтрация по количеству друзей и поиск пользователей без друзей.
4. Разработать пользовательский интерфейс (UI) для отображения карточек,
   добавления/удаления пользователей и управления друзьями.
5. Обеспечить асинхронное выполнение операций (через `Promise` и `setTimeout`) и
   сохранение состояния в `localStorage`.

## Реализация

Работа разделена на два логических файла: `model.js` и `main.js`.

Реализован класс User. Функции из задания 4.2 реализованы.

Вся логика работы с DOM вынесена в `main.js`. Для сохранения состояния между
сессиями используется `localStorage` (с предварительной сериализацией данных в
JSON). При загрузке страницы данные извлекаются из хранилища и преобразуются
обратно в экземпляры класса `User`, чтобы сохранить доступ к методам. Добавление
и удаление элементов выполняются асинхронно: используется функция-обертка
`asyncDelay`, возвращающая `Promise`, который разрешается через `setTimeout`. На
время операции кнопки блокируются (`disabled`). При каждом изменении данных
вызывается функция `render()`, которая полностью перерисовывает список карточек
на основе актуального массива `users`. Карточки стилизованы с использованием
эффекта всплытия при наведении (`hover`).
