# Лабораторная работа 1

## Задание

Вариант 11: Создать список задач, где каждый элемент списка имеет разную иконку
в зависимости от статуса задачи. Иконки добавляются с помощью псевдоэлементов
CSS, используя символы Unicode.

## Реализация

В файле `index.html` создан семантический список `<ul>`, элементы которого имеют
классы `.task--done`, `.task--cancelled`, `.task--in-progress`. Иконки добавлены
через псевдоэлемент `::before` с использованием Unicode-символов. Стили
разделены по классам в зависимости от статуса задачи.

## Запуск

Откройте `index.html` в браузере.
